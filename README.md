# Zabihullah Isaqi — multilingual academic website

Personalised starter site based on the template kindly shared by its original owner. It preserves the four-language site structure (English, Persian/Dari, Pashto, Arabic), navigation, courses, blog, activities, media pages, and responsive styling. Original owner's personal blog and activity catalogues have been cleared so they are not republished as yours.

## Publish on GitHub Pages
1. Open https://github.com/zabihullah-isaqi/zabihullah-isaqi.github.io
2. Upload the contents of this repository to the `main` branch (not the enclosing folder).
3. In **Settings → Pages**, choose deployment from the `main` branch if it is not already configured.
4. Run `python3 scripts/build.py` before committing edits when working locally; then run `python3 scripts/check.py`.

## Before public launch
- Confirm the email address and add your own profile photo.
- Add your own posts, courses, publications, activities, and media links. The original author's text and personal media have not been retained in the blog/activity catalogues, but some legacy standalone pages still need content review before public launch.
- This repository is a prepared starter copy; it has not been pushed to your GitHub account.
